## What's new since v0.1

The kernel series is 148 patches on Linux 7.3 (v0.1 had 143).

### Stock tuning

Hardware tuning copied from stock OxygenOS/LineageOS. [STATUS.md](https://github.com/LuCiLuna/oneplus9pro-arch/blob/v0.2/docs/STATUS.md#stock-tuning)
lists how each part was checked; how they look and sound in daylight hasn't been judged yet.

- **Camera colours:** the main, ultrawide, telephoto and front cameras use stock's colour
  correction matrices, read out of its Chromatix tuning files, through libcamera's software ISP.
- **Sunlight boost:** the panel's high-brightness mode (600–800 nits) switches on in bright light
  and off again, like stock's automatic brightness (patch 0147, `op9-sunlight-hbm`). The brightness
  slider is unchanged.
- **Natural colour:** an optional sRGB mode. The panel is Display P3, so ordinary content looks
  oversaturated, like stock's default Vivid mode; Natural maps it onto the panel's gamut in the
  display engine (patch 0148). Vivid stays the default.
- **360 Hz touch:** an optional report rate of 360 Hz, which stock only uses in game mode
  (patch 0146). The default stays 120 Hz.
- **Quick settings:** Natural colour and 360 Hz touch are Phosh quick settings that remember their
  state (`userspace/phosh-op9-quick-settings`).
- **Headphones:** the amplifier runs in stock's HiFi mode, and the headset mic gets stock's gain,
  about 3 dB more.

### Desktop mode

- Plugging in a display offers a full GNOME session on it; unplugging brings Phosh back.
- The phone screen becomes a keyboard, a trackpad or both, drawn on the panel, with a vibration
  tick per key (patch 0145 plays each vibration at its own strength).

### Fixes

- **Haptics:** Squeekboard's key presses are felt again. Starting the motor no longer rewrites its
  whole setup, so 7 ms ticks aren't swallowed.
- **SIM:** slow cards get up to 3 minutes to show their USIM app, where some data SIMs used to be
  given up on. Data-only APNs (such as AT&T's NRBROADBAND) are documented.
- **Lockups:** hung tasks, soft lockups and workqueue stalls now reboot the phone once the report
  is in the journal (`op9-lockup-watch`), and GPU crash dumps are kept in
  `/var/lib/op9-devcoredump`.
- **Desktop mode:** the panel is kept on its own display blocks (patch 0144), so it comes back
  after an external display.

### Other additions

- zram swap (about 5.4 GB, compressed in RAM) and Steam through the FEX x86 emulator.
- Install guide: the Files app's network and device backends, everyday apps and codecs, Flatpak,
  Chrome and Claude Code.
- Findings written up: where stock's speaker processing really runs, the Chromatix colour-matrix
  layout and the panel's gamut and HBM ([HARDWARE.md](https://github.com/LuCiLuna/oneplus9pro-arch/blob/v0.2/docs/HARDWARE.md)),
  and the fingerprint reader investigation ([FINGERPRINT.md](https://github.com/LuCiLuna/oneplus9pro-arch/blob/v0.2/docs/FINGERPRINT.md)).

### Upgrading from v0.1

Install the new `Image` and modules as before, then from a checkout of this tag copy `rootfs/` over
the root filesystem again and:

```sh
sudo systemctl enable --now op9-sunlight-hbm op9-lockup-watch
sudo udevadm control --reload && sudo udevadm trigger
```

Build `userspace/phosh-op9-quick-settings` and add its quick settings as in
[INSTALL.md](https://github.com/LuCiLuna/oneplus9pro-arch/blob/v0.2/docs/INSTALL.md#8-patched-packages).
